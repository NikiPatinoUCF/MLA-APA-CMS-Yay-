## 🆕 New Features Overview

### 1. Citation Builder (citation-builder.html)
- **Access:** From home page feature card or help page
- **What it does:** Drag and drop citation components into correct order
- **Includes:** 9 practice puzzles (3 each for MLA, APA, CMS)
- **Features:** Answer checking, show answer, reset, next challenge

### 2. In-Text Citations Guide (in-text-citations.html)
- **Access:** From home page feature card or help page
- **What it does:** Teaches how to cite sources within text
- **Includes:** Comprehensive guides for MLA, APA, and CMS
- **Features:** Tabbed interface, examples, practice questions, comparison chart

### 3. Lesson Mode (lesson.html)
- **Access:** Automatically shown before each quiz
- **What it does:** Teaches key concepts before testing
- **Includes:** Lessons for all style guides and difficulty levels
- **Features:** Examples, tips, skip option, centered layout

### 4. Improved Visual Centering
- **What changed:** Added CSS utilities for better vertical centering
- **Effect:** Content displays more centered on screen across all pages
